# קובצי המקור של TeamCode

[English](readme.md)

תיקייה זו מכילה את קוד הרובוט הפעיל של התבנית. TeamCode היא תיקיית מקורות ביישום Android של Dairy בשורש, ולא מודול Gradle נפרד. פתחו את פרויקט השורש ב־Android Studio/IntelliJ, בחרו את הבקר ותצורת יישום Android ולחצו **Run ▶** לבנייה ולהתקנה. סנכרנו אחרי שינוי הגדרות בנייה או כשהתוכנה מבקשת; עריכות Java רגילות דורשות בדרך כלל רק Run.

התחילו ב־[README של הפרויקט](../../../../../../../../README.he.md) וב[מדריך התכנות](../../../../../../../../doc/guide/he/01-setup.md).

- `opmodes`: תוכנית Starter TeleOp הפעילה ושגרות הקבוצה.
- `examples`: שבעה שיעורים מושבתים להעתקה, שינוי שם והפעלה מכוונת.
- `subsystems`: אחריות למנגנונים ומפעלי פקודות; `drivetrain/PedroDrive` אחראי לעוקב.
- `pedroPathing`: תצורות Pedro 3 משותפות, רישום AutoTune ותיקיית `procedures` להליכי mecanum,‏ Pinpoint,‏ Foresight ואימות.
- `RobotCommandOpMode`: תמיכה משותפת בביטול מתזמן ובמחזור החיים.

Starter TeleOp דורש ארבעה מנועי mecanum,‏ Pinpoint וגלגלי אודומטריה תואמים. הגדירו את הרובוט ומדדו היסטים לפני הרצה. שיעורים 01 ו־07 אינם דורשים ציוד היקפי.

פעלו לפי [הליך ההעתקה](../../../../../../../../doc/guide/he/10-workflow.md#copy-an-example) כדי להוסיף OpMode. שמרו מופע תת־מערכת אחד לכל מנגנון פיזי ושמרו על ניקוי בביטול וב־STOP.

דוגמאות FTC המקוריות ב־`FtcRobotController` וקוד הרובוט הישן ב־`doc/archive` הם מקורות לעיון מחוץ לקבוצות המקורות המתקמפלות. העתיקו והתאימו דוגמה למקורות TeamCode הפעילים כדי לקמפל אותה. שמרו הודעות זכויות רלוונטיות בשימוש חוזר בקוד.
